# Analyst-lab-Africa-project-1-FinTrust-Digital-Banking-Performance-Risk-Analysis
#Project Overview
Analysis of 12,000 transactions and 1,500 active customers (Jan–Mar 2026) to evaluate digital channel performance, platform failure rates, and compliance risk flags.
#Key KPIs
Active Customers: 1,500 distinct IDs  
Total Volume: 12,000 transactions  
Success Rate: % of completed transactions 
Risk Review Rate: % of flagged transactions  
Channel Failure Rate: Error rates by Web, Mobile App, USSD, and ATM 
#Data Summary
Customer Data: 1,500 rows, 12 columns, 0 missing values.   
Transaction Data: 12,000 rows, 11 columns (96 missing in Device Type & Location).  
Key Relationship: Joined via Customer ID.
